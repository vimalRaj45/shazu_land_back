# Shazu Soft Technologies - Backend API

Fastify, PostgreSQL, JWT Authentication, and Email Engine backend for Shazu Soft Technologies.

## Setup & Running
1. Copy `.env.example` to `.env` and fill in your PostgreSQL and JWT details.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the server:
   ```bash
   npm start
   ```
   or for development:
   ```bash
   npm run dev
   ```
