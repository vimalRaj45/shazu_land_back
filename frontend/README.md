# Shazu Soft Technologies - Frontend Website

Modern Single Page Application (SPA) website for Shazu Soft Technologies.

## Features
- Dynamic Single Page Application (SPA) router with seamless page transitions.
- Fully responsive modern design with light/dark theme switcher.
- Configurable API Base URL via `js/config.js` or `localStorage`.

## Deployment
Can be deployed to any static host such as Vercel, Netlify, Cloudflare Pages, GitHub Pages, or AWS S3.
